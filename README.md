# 对话渲染系统

SillyTavern / TauriTavern 前端扩展。将角色台词和心理活动显示为带头像、情绪标签的对话，叙述和动作保留普通正文。

## 安装与更新

在酒馆「扩展 → 安装扩展」中填写：

```text
https://github.com/liushuangls/ST-DialogueRenderer
```

安装或更新后刷新页面，在扩展设置里打开「对话渲染系统」。无需额外管理脚本或渲染正则。

**2.0 是协议变更版本。** 只识别下面的 `@say` / `@think` 格式，旧 `@bubble` 消息保持原始显示，不会改写聊天记录。旧格式规则、旧情绪提示词模板不再参与注入；需要的额外要求可填写到「补充提示词」。升级继续使用已有头像、美化和字体的数据空间。

## 对话协议

```text
她放下杯子，轻轻点头。

@say:林雪|温和|先坐一会儿吧。
@think:林雪|担忧|他的脸色还是不太好。
```

- `@say` 表示说出口的台词，`@think` 表示未说出口的想法，每条独占一行。
- 前两个 `|` 分隔姓名和情绪，后面全部是正文；正文可以包含 `[Enter]`、`A | B` 和 Markdown。
- 姓名保持稳定一致；用户角色和其他角色使用同一种格式，各自填写自己的名字。
- 情绪不能为空，可自然描述。匹配词表的词使用对应差分；池外词原样显示并使用基础头像。
- 叙述、动作、环境直接写普通段落。渲染器不要求 `<now_plot>` 或 `<content>` 容器。
- Markdown 的斜体、粗体只影响排版，不改变台词与心理活动的类型。

无效的完整标记保留原文，并在扩展设置中显示消息编号与原因。正在流式生成的最后一行可暂时不完整，生成结束后会重新检查。

## 设置

- **启用对话渲染**：同时控制消息显示和协议提示词注入。关闭后恢复原始显示。
- **最近 AI 回复数量**：默认 3，可填 1–100。只计实际 AI 回复，用户、系统和工具消息不占名额。
- **头像、情绪与正文美化**：管理分卡/全局头像、情绪差分、主题色、字体和排版。管理面板在第一次打开时加载。
- **正文美化预览**：拖动控件只修改预览。保存后应用；关闭未保存的面板会恢复保存值。
- **情绪与提示词**：固定协议由程序生成。可编辑补充要求、情绪参考词和差分匹配词；完整注入预览显示模板与字符数，宏由酒馆在生成时替换。每组只注入一个参考词，其余词用于本地匹配。

管理面板顶部「导入 / 导出」跟随当前页签：头像页导出图片与差分，美化页导出样式，情绪页导出补充提示词与完整情绪配置。角色重命名会一起移动基础头像、差分和主题色；目标名字已有资源时拒绝覆盖。

## 渲染与数据

扩展装饰酒馆完成显示正则、Markdown 和清理后的消息 DOM，不重复解析 Markdown，也不修改保存的原文。代码块、iframe、折叠详情和专用前端节点保持各自的渲染方式。

静态聊天仅监听正文和消息挂载变化，计时器、计数和头像加载不触发气泡重建。TauriTavern 的有界投影使用 ChatSurface 内容生命周期，卸载时同步清理视图。

字体目录在当前页面内缓存；「刷新字体列表」会重新请求目录。普通字号、颜色调整只更新 CSS；字体资源没有变化时复用已有节点和 Blob URL。

头像、样式及字体沿用现有 IndexedDB 与 `/user/files` 同步文件。跨设备传输由宿主的 `user.files` 同步范围负责。提示词模板为本地配置，可通过情绪页导出/导入；新模板格式为 2.0，包含补充要求与情绪词表。

## 开发与发布

使用原生 ES modules，无运行时构建依赖。`node_modules` 只用于开发测试。

```sh
npm ci --ignore-scripts
pnpm run check
npm run preview
```

浏览器回归页：`http://127.0.0.1:8766/`。它使用独立数据库和模拟宿主，不访问真实聊天或头像。自动化测试覆盖协议、DOM 原样恢复、流式尾行、生命周期、预览与保存、字体缓存，以及存储、同步、重命名和导入导出。

发布版本以 `package.json` 为准：

```sh
npm version patch --no-git-tag-version
pnpm run check
```

`version` 钩子会同步 manifest 和所有本地 JS/CSS 依赖 URL，包含按需导入的管理面板；检查会拒绝遗漏的版本参数。修改版本号后也可执行 `npm run version`。

模块职责和生命周期约束见 [docs/Architecture.md](docs/Architecture.md)。

# 对话渲染系统

SillyTavern / TauriTavern 前端扩展。将角色台词和心理活动显示为带头像和姓名的轻气泡，叙述和动作保留普通正文。

## 安装与更新

在酒馆「扩展 → 安装扩展」中填写：

```text
https://github.com/liushuangls/ST-DialogueRenderer
```

安装或更新后刷新页面，在扩展设置里打开「对话渲染系统」。无需额外管理脚本或渲染正则。

**2.0 是协议变更版本。** 只识别下面的 `@say` / `@think` 格式，旧 `@bubble` 消息保持原始显示，不会改写聊天记录。可在「情绪与提示词」直接编辑完整注入提示词。升级继续使用已有头像、美化和字体的数据空间。

## 对话协议

```text
她放下杯子，轻轻点头。

@say:林雪|温和|先坐一会儿吧。
@think:林雪|担忧|他的脸色还是不太好。
```

- `@say` 表示说出口的台词，`@think` 表示未说出口的想法，每条独占一行。
- 前两个 `|` 分隔姓名和情绪，后面全部是正文；正文可以包含 `[Enter]`、`A | B` 和 Markdown。
- 姓名保持稳定一致；用户角色和其他角色使用同一种格式，各自填写自己的名字。
- 情绪不能为空，可自然描述。匹配词表的词使用对应差分；池外词使用基础头像，聊天中隐藏语气词。
- 叙述、动作、环境直接写普通段落。渲染器不要求 `<now_plot>` 或 `<content>` 容器。
- Markdown 的斜体、粗体只影响排版，不改变台词与心理活动的类型。

无效的完整标记保留原文，并在扩展设置中显示消息编号与原因。正在流式生成的最后一行可暂时不完整，生成结束后会重新检查。

## 设置

- **启用对话渲染**：同时控制消息显示和协议提示词注入。关闭后恢复原始显示。
- **最近 AI 回复数量**：默认 3，可填 1–100。只计实际 AI 回复，用户、系统和工具消息不占名额。
- **头像、情绪与正文美化**：管理分卡/全局头像、情绪差分、主题色、字体和排版。管理面板在第一次打开时加载。
- **正文美化预览**：白天、黑夜和羊皮卷各有配套字色与 1px 淡描边。轻气泡左下方显示头像，姓名居中排在头像上方。台词使用「」引号，心声使用斜体。默认使用黑体，旁白 17px、台词 15px，行高均为 1.85。调整正文字号时，台词比正文小 2px。纸色只铺在正文和对话片段，思考折叠栏沿用自己的背景。头像尺寸、形状和压缩设置收在「头像与图片」。编辑时实时预览，保存生效。
- **情绪与提示词**：直接编辑完整注入提示词，保存后原样注入；未保存的编辑不影响生成，恢复默认可取回内置模板。宏由酒馆在生成时替换。下方情绪词表用于本地差分匹配，修改词表不会覆盖提示词；提示词里的参考词可直接编辑。

管理面板顶部「导入 / 导出」跟随当前页签：头像页导出图片与差分，美化页导出样式，情绪页导出完整提示词与情绪配置。角色重命名会一起移动基础头像、差分和主题色；目标名字已有资源时拒绝覆盖。

头像和情绪差分使用本地图片上传，支持酒馆文件同步。已移除远程图片 URL、远程拉取和缓存管理；JSON / ZIP 备份始终包含实际图片，缺少图片的文件会在写入前拒绝导入。

## 渲染与数据

扩展装饰酒馆完成显示正则、Markdown 和清理后的消息 DOM，不重复解析 Markdown，也不修改保存的原文。代码块、iframe、折叠详情和专用前端节点保持各自的渲染方式。

静态聊天仅监听正文和消息挂载变化，计时器、计数和头像加载不触发气泡重建。TauriTavern 的有界投影使用 ChatSurface 内容生命周期，卸载时同步清理视图。

切回前台或网络恢复时，头像和样式同步会原位更新已有气泡；资源没有变化就不改动正文 DOM，避免刷新时短暂收缩聊天高度、丢失阅读位置。

默认黑体依次匹配设备上的中文黑体字体。也可选择系统字体、思源宋体或霞鹜文楷。后两项先使用已安装的同名字体，缺少时从固定版本的 jsDelivr 字库按所需字符加载 WOFF2 分片。离线且没有缓存时使用系统衬线字体。扩展仅附字体分片索引。已保存的排版继续生效，在「正文美化」恢复默认并保存即可采用整套新排版。

头像、样式及字体保存在现有 IndexedDB 与 `/user/files`。全局样式使用新版 v2 同步清单，以当前本地已保存的有效设置和字体初始化，不再读取含有废弃字段的旧同步状态。跨设备传输由宿主的 `user.files` 同步范围负责。提示词模板为本地配置，可通过情绪页导出/导入；模板格式为 2.1，包含完整提示词与情绪词表。

## 开发与发布

使用原生 ES modules，无运行时构建依赖。`node_modules` 只用于开发测试。

```sh
npm ci --ignore-scripts
pnpm run check
npm run preview
```

浏览器回归页：`http://127.0.0.1:8766/`。它使用独立数据库和模拟宿主，不访问真实聊天或头像。自动化测试覆盖协议、DOM 原样恢复、流式尾行、生命周期、预览与保存、字体缓存，以及存储、同步、重命名和导入导出。

发布版本以 `package.json` 为准：

```sh
npm version patch --no-git-tag-version
pnpm run check
```

`version` 钩子会同步 manifest 和所有本地 JS/CSS 依赖 URL，包含按需导入的管理面板；检查会拒绝遗漏的版本参数。修改版本号后也可执行 `npm run version`。

模块职责和生命周期约束见 [docs/Architecture.md](docs/Architecture.md)。
